# 共享节点：FDE 证据卡

证据卡不是证书，也不评价"天赋"。它让雇主或客户看见你完成了什么、怎样验证以及还有什么未证明。FDE 求职时，证据卡比简历上的形容词值钱。

## 模板

```markdown
# FDE Evidence Card

项目：
解决的业务问题：
客户类型（脱敏）：

## 可获得的产物
- 作品地址或获取方式：
- 仓库或版本记录：

## 需求侧证据
- 我观察/访谈了谁的角色（脱敏）：
- 我定义的问题（一句话）：
- 我排除掉的表面需求：

## 交付与验收证据
- 主路径：
- 边界 / 失败路径：
- 评估集或测试的真实输出：
- 一位真实用户的反馈：

## 一次失败与修复
- 怎样复现：
- 根因：
- 修改：
- 怎样确认没有复发：

## 未验证和剩余风险
-

隐私检查：不包含 Key、密码、客户机密、真实人名公司名和未授权内容。
```

## 规则

- 只记录实际发生的行为；模拟实验必须标明。
- 客户项目不能公开时，交付脱敏证据同样有效。
- Agent 可以整理文字，但学生必须确认每条事实。
- 证据卡完成后，学生自行决定是否把链接提交到 `WALL.md`。
