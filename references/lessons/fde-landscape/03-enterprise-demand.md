# 企业需求挖掘：热力图与五局限

## 目标

学生能用"决策层意识 × 企业规模"热力图定位客户，能讲清通用大模型进企业失效的五个原因，以及 Agent 落地要面对的四个挑战。

## 讲授

### 需求热力图

曹其睿给独立 FDE 团队画了一张热力图：

- **纵轴：CEO/决策层的 AI 意识**，三档——完全没意识/隐约听说过（只用过豆包）；有痛点、相信 AI 能解决但不知如何落地；着急落地（已在同行身上看到结果）；
- **横轴：企业规模**。小型典型 30–50 人、单一工作流、老板直管（配音工作室、小厂外贸部门、小型 HR 服务商）；中型有更多独立职能部门、多条工作流；大型是央国企、上市公司、细分龙头，多层级多决策人。

各玩家的覆盖区域：

- 大型云厂商主攻**大型 + 有痛点/急于落地**的中高区域，投大量人力物力；
- 中型企业被云厂商的渠道体系覆盖（渠道能力欠缺但在学）；
- **小型和部分中型企业是独立工作室的高性价比区**；
- "完全没意识"的客户对 FDE 来说性价比最低——你不仅要解决问题，还要承担老师的责任。

用法：不管是求职还是接单，拿这张图比对——你的（或你雇主的）目标客户落在哪个格子，为什么。

### 通用大模型进企业失效的五个局限

场景假设：老板给员工开通了一个独立聊天工具，却没有接入企业系统与工作流，效果还是不行。以下局限针对这种使用方式；具备工具、权限和任务循环的产品可能已补上其中一部分能力。

1. **没有执行能力**：Chatbot 只会说"你可以做这个做那个"，不能帮你执行——"只需要一个人指挥的话，你老板已经够了"；
2. **缺乏企业上下文**：企业里大量隐性规则（供应商怎么处理、招标走什么步骤、谁审查流程）没写成文件，员工耳濡目染才知道，通用模型不知道；
3. **单轮交互**：真实任务多步骤且会失败，需要持续循环、遇到失败找 workaround——这是正常员工该做的事，模型进企业也必须做；
4. **数据隔离与缺位**：报表和决策依赖企业数据，数据接不进来，模型只能泛泛而谈；
5. **输出不可靠**：涉及钱财、法律文件、合同，"你敢用吗？你是要承担责任的"。

结论：企业需要的不是对话框，而是有生产级行动能力的 **Agent**。企业为结果付费，不为聊天付费。

### Agent 什么时候才真正能用

- 2023 年 AutoGPT 等实验性框架出现，但规模和稳定性不足；
- 2024 年下半年，OpenAI 等大厂极大充实工具调用能力、提升稳定性，基础应用厂商开放核心能力；
- **2024 年 11 月 25 日 Anthropic 发布 MCP**，提供一种连接外部系统的开放协议（[发布说明](https://www.anthropic.com/news/model-context-protocol)）；
- Computer Use 让 Agent 能像真人一样操作电脑和浏览器；
- Agent 的四项技术能力：**规划、工具调用、循环与自我修正、记忆与上下文**；
- 课程以这些进展解释 Agent 为何更有落地条件；一个具体应用能否进生产，仍由业务风险、权限边界和评估结果决定。

### Agent 落地的四个挑战 = FDE 要解决的问题

1. **业务 know-how**：关键业务流程的隐性知识没有书面化；
2. **数据**：很多 50 人规模的企业连飞书/ERP 都没用，文件数据在微信群里乱传；
3. **组织**：新技术与旧架构的冲突——有员工清楚地意识到 AI 和自己的利益冲突，"全自动化了，要我干嘛？"；
4. **决策层认知**：老板不是付了钱就行，要投入精力梳理业务、设计组织、调动积极性，还要持续投入财力。

## 常见误区

- "老板支持 + 买了会员 = AI 转型启动了"——五个局限一个都没解决；
- "Agent 能力强了，落地就是技术问题"——四个挑战里三个是业务、数据、组织问题；
- "客户越小越好做"——没意识的客户要付教育成本，性价比反而低。

## 实验

1. 在 `evidence/demand-map.md` 画出热力图：横轴规模、纵轴意识，把熟悉的组织以“A 类小企业”等匿名标签放进去，标出判断依据。没有真实接触证据的格子写“假设”；
2. 选一个你熟悉的组织（公司、学校、社团），用五个局限逐条检查："如果明天给所有人发一个 Chatbot 账号，哪一条最先卡死？"写下具体场景；
3. 对同一个组织，用四个挑战逐条检查，写下你预判最大的那个障碍和理由。

## 证据

`evidence/demand-map.md` 含匿名对象的热力图，以及同一场景下“五局限 + 四挑战”的对照记录；每条注明观察证据或待验证假设。没有接触组织时可用虚构场景演练，并如实记录。
