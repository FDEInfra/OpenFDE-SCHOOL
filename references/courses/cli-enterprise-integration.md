# ④ CLI 打通企业内部系统

状态：beta（大纲已整理，课节待蒸馏）

来源：OpenFDE ✖️ 观猹 FDE 共学营第 4 课，视频全长 02:37:11。[在线观看](https://openfde.net/zh/resources/guancha-fde)

## 唯一承诺

上完这节课，你能判断企业内部系统该用 MCP、API 还是 CLI 接入，并能动手把一个内部系统封装成 CLI、再包成 Skill 挂给智能体，让 Agent 端到端完成跨系统的读取与写入操作。

## 内容大纲

| 节点 | 时间段 | 要点 |
|---|---|---|
| 为什么用 CLI 而不是 MCP | 00:00:00–00:05:20 | 2026 年 3 月 Perplexity 创始人兼 CTO 在 ASK 大会表态内部正从 MCP 转向 API 和 CLI；MCP 的 schema 启动即占上下文 token、多一层耗时与出错点、认证体验差、有注入越权风险、审计复杂、还要起服务 |
| 行业 CLI 化现状与数字化黄金公式 | 00:05:20–00:08:12 | 钉钉、企业微信、飞书、瑞幸咖啡均已提供官方 CLI（多用 Node）；大厂 2026 年初平台 MCP 化、年中转向 CLI 化；企业数字化黄金公式=系统 CLI 化+流程 Skill 化+员工 Agent 化 |
| CLI 与 HTTP API 的关系 | 00:08:12–00:10:45 | CLI 负责参数解析、读配置、构造 HTTP 请求、展示结果；CLI 运行在本地、HTTP 接口运行在服务端，CLI 是服务的一个入口 |
| 实战：把报销系统封装成 CLI | 00:10:45–00:18:15 | 先把前后端代码喂给 AI，选 Node+TypeScript 可发到企业内部 NPM 注册中心用 npx 安装（演示用 Python）；先做登录和查询跑通；登录改为弹登录框存 cookie 而非命令行输密码；带 -v、-h、login、logout、install.sh 全局安装 |
| 把 CLI 封装成 Skill | 00:18:15–00:23:55 | Skill 必须包进 CLI 的自动下载安装；只放最核心功能，其余让 Agent 通过 -h 自行发现；提到 OpenCLI 可自动把系统封装成 CLI（讲师未采用，原因见经验段） |
| 经验与坑：范围、安全、封装粒度 | 00:23:55–00:30:13 | 先跑通再铺开、按优先级分批；危险接口（如发布）留人工确认并在 Skill 里强调影响；系统多就接统一身份认证；按任务/业务导向聚合封装而非一对一硬包 API；参数超过两个用 JSON 传递 |
| 经验与坑：工程化与团队规范 | 00:30:13–00:38:57 | 前端原有的校验、幂等键必须搬进 CLI；单元测试覆盖率冲到 90%+并做集成与端到端测试；团队统一技术栈、版本规范与发布；把"两参数以上用 JSON"这类经验写进仓库根目录 AGENTS.md（团队用 Claude Code 则写 CLAUDE.md）沉淀复用；Dokobot 示范了反向用 CLI 装 Skill |
| 汇报视角与 MCP/CLI 选型 | 00:38:57–00:42:43 | AGENTS.md 给智能体看、README 给人看；向老板汇报用业务语言（半小时操作变三分钟、提效十倍）；MCP 适合长尾动态扩展、CLI 适合高频强 SLA 场景，二者非替代关系 |
| 嘉宾一：阿里云百炼 CLI 与案例 | 00:44:12–01:11:41 | 若琪演示一句 prompt 生成 2 分钟 16:9 日系校园视频：Agent 做需求理解、规划、分镜、生成、拼接五步，用 Qwen Code 调 HappyHorse、Qwen-Image 2.0、CosyVoice V3 与 spark-video skill；30 秒接入 CLI；路径递进：本地工作流→Managed Agent 云端分发→模型调优与平台管控；开源 OpenAgentPack、OpenWork |
| 百炼 CLI 现场答疑 | 01:11:41–01:28:17 | CLI 化做法=把源码给 Agent 参考 GitHub CLI 改造；MCP 是给 Agent 用的 API、CLI 是包了多个 API 的完整产品；CLI 免费但调模型能力需购买百炼服务、需配 API key |
| 嘉宾二：DeskClaw 企业版演示 | 01:28:17–01:40:17 | 王仿演示业务翻译平台（业务专家传文档自动生成业务工作流，按 RRPO——input/process/output/异常处理——确认每个 task）、技术实施平台（挂 Skill/工具/知识库）、运维平台与运营看板 |
| 企业 Agent 落地的挑战 | 01:40:17–01:49:37 | 企业 Agent 要求整链路准确率稳定 90% 以上（个人 70-80% 已惊艳）；单节点 95% 准确率串 10 个节点只剩约 60%；工具/Skill 超 20 个后 Agent 越来越不可控；2026 上半年全球已有近一亿 Agent 但大量停在 Demo 阶段 |
| 落地六步法与任务七类型 | 01:50:59–02:15:04 | 选任务（黄金标准：人力密集型+知识密集型，编码落地最好）→说清任务（业务翻译/本体）→装配能力→稳定执行（断点续传、状态快照）→价值可量化→模板复用；任务分流程执行、审核校验、专业问答、根因分析、决策辅助、内容生成、运营优化七类 |
| 现场答疑与作业提示 | 02:15:40–02:37:11 | Agent 上线三阶段：AI 测评→影子系统→辅助→自动化；客服是落地最难场景（老板想裁员则专家不愿交 know-how）；纯 RAG 客服"没有市场"，未来客服要懂产品、懂人、懂场景；交付部署在客户本地；作业可用 DeskClaw 完成 |

## 关键事实锚点

- 2026 年 3 月 Perplexity 创始人兼 CTO 在 ASK 大会表态：内部正从 MCP 转向 API 和 CLI（00:01:47）
- 企业数字化黄金公式：系统 CLI 化 + 流程 Skill 化 + 员工 Agent 化（00:07:02）
- 钉钉、企业微信、飞书、瑞幸咖啡均已提供官方 CLI，技术栈多为 Node（00:05:20–00:05:53）
- CLI 参数超过两个就改用 JSON 传递，避免顺序错乱与类型混淆（00:30:13）
- AGENTS.md 是给智能体看的规范沉淀，README 是给人看的（00:38:57–00:39:33）
- 百炼 CLI 视频案例技术栈：Qwen Code + HappyHorse + Qwen-Image 2.0 + CosyVoice V3 + spark-video skill（00:52:25）
- 企业 Agent 上线门槛：整任务链路准确率稳定 90% 以上，剩余 10% 靠人与运维兜底（01:42:30）
- 长链路衰减算术：单节点 95% 准确率，10 个节点后只剩约 60%（01:45:32）
- Agent 上线三阶段：AI 测评 → 影子系统 → AI 辅助 → 有限自动化（02:16:41）
- 选任务两条黄金标准：人力密集型、知识密集型；编码是当前落地最好的场景（01:51:32–01:52:38）
