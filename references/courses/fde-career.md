# ⑧ 加餐：FDE 求职、作品集与创业路径

状态：beta（大纲已整理，课节待蒸馏）

来源：OpenFDE ✖️ 观猹 FDE 共学营加餐课，视频全长 00:50:43。[在线观看](https://openfde.net/zh/resources/guancha-fde)

## 唯一承诺

上完这门课，学员能把训练营项目同时用成两张门票：向左走，产出一份经得起「四信号」自查的 FDE 简历和一个含失败复盘的作品集案例；向右走，看懂独立 FDE 的「审计—交付—陪跑」三段式商业模式，知道自己该走哪条路、第一步做什么。

## 讲师与嘉宾

- 讲师：王十一，OPC FDE（2024 年起独立执业），OpenFDE 合伙人之一，运营 OpenFDE 旗下 DeltaEcho FDE 社区（中文名「先遣网络」）。此前在金融互联网行业工作 6 年，路径为运营 → 产品经理 → 软件工程师 → 企业内部 AI 解决方案架构师；独立后服务 15 家企业客户，横跨医疗、金融、制造、事务所、咨询行业，最高年利润 230 万，公司只有讲师一人。
- 嘉宾：本节课无对谈嘉宾，为讲师单人讲授。

## 小作业（课程原题）

已布置：写一份 FDE 简历。

- 正文原话（00:12:28）：「咱们这周作业就是写一份 FDE 简历。」
- 收尾提醒（00:50:03）：「第一点，简历作业，写完之后记得用四信号自查。」四信号即：端到端交付、客户接触面、生产环境、可量化结果。
- 简历素材直接来自训练营大作业：Day 1 需求说明清单与业务流程图 → 需求挖掘能力；Day 2 SOW → Scoping 能力；Day 3 Skills → 可测试的 AI 能力单元（附测试证据）；Day 4 系统接入 → MCP/API 集成（含权限与异常处理）；Day 5 Eval → 不少于十套用例的验收测试集与量化结论。
- 关联任务：次日 Demo Day 项目路演，讲师称其为「你们第一个作品集案例的发布现场」。

## 关键事实锚点

- FDE = Forward Deployed Engineer，Palantir 发明的军事用语「前沿部署」，不是「前端部署工程师」（00:01:57）
- Palantir 内部分工：Echo = Deployment Strategist（部署策略师，偏业务），Delta = FDSE（Forward Deployed Software Engineer，偏工程）（00:03:03）
- LinkedIn 年度劳动力报告：FDE 岗位 2023–2025 两年涨 42 倍，同期 AI Engineer 涨 13 倍；Indeed：2026 年 4 月岗位发布同比涨 729%（00:06:55）
- 国内薪资样本：字节豆包 FDE 月薪 3.5–7 万×15 薪；蚂蚁数科 4–6 万；智谱 FDE 负责人 6–8 万；阿里云方案架构师 2–5 万×16 薪（00:09:29）
- 全球薪资光谱：Palantir 底薪 13.5–20 万美金，Scale 18–22 万，Anthropic 20–30 万，OpenAI 总包 35–55 万，国内头部 AI 公司 50–100 万人民币加驻场补贴（00:10:04）
- 简历四信号（1000 份 JD 分析）：端到端交付、客户接触面、生产环境、可量化结果；JD 高频技能前五：Python、AI Agents、TypeScript、AWS、LLM（00:12:28、00:13:33）
- 海外 FDE 岗位聚合站「Plank」（音译存疑），称收录全球在招 FDE 岗位 1200+（00:19:18）
- 拆解面（FDE 面试的灵魂轮次，OpenAI 与 Anthropic 也用此形式）真题：伦敦 8000 条出租车运营记录、八个字段、一周内可开发部署的方案；评分表七件事中五条与代码无关（00:27:51、00:28:58）
- Palantir Mafia：校友至 2024 年创办 111 家公司、累计融资 116 亿美金，YC 现任 CEO 是 Palantir 第十号员工；支付公司 Ramp 的 16 人 FDE 团队里 7 个是前创始人（00:32:22、00:33:32）
- 独立 FDE 三段式商业模式：审计（付费诊断 + ROI 报告）、交付（目标层验收、按约定 Eval 测试集结算）、陪跑（按月/年订阅迭代）；讲师单人服务 15 家企业客户、最高年利润 230 万（00:34:36、00:34:05）

## 完成证据（课节蒸馏后生效）

- 交出一页 FDE 简历，含一句话定位、核心技能表、按五段式（业务背景/需求边界/方案选型/可量化结果/可复用资产）展开的项目经历，并用四信号逐条自查打勾。
- 交出结营项目的作品集案例一份，结构含失败复盘段落，并按三层颗粒度（媒体长文 / GitHub README / 一页 PDF）产出至少一层，全部素材完成脱敏三件套。
- 写出自己的目标岗位清单（含国内外别名检索词：解决方案架构师、交付工程师、AI 应用工程师等），并用五个压力测试标注每个岗位的真假 FDE 判断；或写出独立 FDE 路线的首单计划（目标客户画像、付费诊断报价与可抵扣设计、目标层验收条款草案）。
