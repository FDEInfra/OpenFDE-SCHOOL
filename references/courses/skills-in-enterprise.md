# ③ Skills 的企业实践

状态：beta（大纲已整理，课节待蒸馏）

来源：OpenFDE ✖️ 观猹 FDE 共学营第 3 课，视频全长 02:00:51。[在线观看](https://openfde.net/zh/resources/guancha-fde)

## 唯一承诺

上完这门课，学生能按「先定义输出 → 反推输入 → 捋清步骤 → 建立测评集」的标准流程，把自己工作中一个模糊的高频场景封装成可复用、可迭代的企业级 Skill，并说清楚 FDE 岗位在客户现场到底做什么。

## 讲师与嘉宾

- **雾明老师**（主持人多次口称「悟鸣」，自我介绍为「雾明」）：Qoder 官方大使，前蚂蚁集团 A 层工程师，公众号「雾明AI」，2024 年起做 AI 业务应用，曾在阿里、蚂蚁多个 BU 内部分享。主讲「企业 Skills 的极速入门」（00:04:48）。
- **瑞老师**：未来式智能的在职 FDE，公司 C 端产品为「代代AI」（Profyt 代代），负责分享 FDE 岗位实况与入门路径（01:20:07）。

## 关键事实锚点

- 雾明：Qoder 官方大使、前蚂蚁集团 A 层工程师、公众号「雾明AI」，2024 年起做 AI 业务应用（00:05:22）
- Skill 发展时间线：2023 年出现雏形，2025 年 10 月正式提出（音译「SR B G」，存疑），2026 年初大爆发（00:10:01）
- Skill 最大创新是渐进式加载：启动只加载名称和描述等元信息，触发后才加载正文（00:11:39）
- 创建 Skill 核心方法论：先定义输出 → 反推输入 → 捋清步骤 → 定性/定量测评（00:27:02）
- Skill 的 description 不要写长，部分智能体超过 200 或 1024 字符会直接截断（00:54:55）
- SkillOptimizer：融合 Anthropic 官方 Skill 最佳实践、谷歌 Skill 设计模式与个人经验，已上架 Qoder 能力市场、GitHub 开源，大厂内部每月近百人下载（01:07:46）
- FDE 岗位热度：OpenAI 五月成立 150 人 FDE 独立公司，谷歌同步招聘数百名 FDE；领英统计 2023–2025 年 FDE 岗位增长 42 倍，2025 年前九个月招聘发布量同比增长超 800%；a16z 称其为科技圈最火岗位（01:21:18–01:22:30）
- 企业侧痛点：很多企业 AI 工具闲置率超过 60%，「演示很惊艳，落地没人会」（01:23:01）
- FDE 概念起源：Palantir（彼得·蒂尔创办）约 20 年前服务美国军方与政府时被逼出来的岗位（01:26:52）
- 代代AI 的 HR 场景案例：100 份简历自动解析打分，筛选时间从 4 小时降到 5 分钟（01:48:17）

## 完成证据（课节蒸馏后生效）

- 完成小作业并可展示产物；
- 能用自己的话复述本课核心方法论（先定义输出 → 反推输入 → 捋步骤 → 建测评集）；
- 展示一个自己封装的 Skill 文件夹，内含 skill.md、按自由度分档的步骤设计，以及 Evals 文件夹下的测评集（evals JSON 含 expected output），并能演示跑一遍测评说明优化前后差异。
