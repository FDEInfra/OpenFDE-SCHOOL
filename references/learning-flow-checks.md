# 入学、选课与续学验证

本检查针对真实导师会话与磁盘存档。包校验通过不代表课堂流程通过；需要实际运行 Codex 或 Claude Code，并查看回复、工具记录和存档。

## 隔离准备

在两个不同的空项目中提供同一份技能。Codex 可使用项目 `.agents/skills/fde`，以 `$fde` 调用；Claude Code 使用其技能目录和 `/fde`。两个项目约定使用同一独立学习存档目录，勿覆盖个人默认存档。

只向导师提供运行条件：独立存档位置、学习产物的项目目录，以及不修改课程源文件。不把下表期望回复交给被测导师。每次开启全新会话，确保续学依赖磁盘记录而非上一轮聊天。

## 场景与判定

| 场景 | 学生输入 | 应检查的行为与证据 |
|---|---|---|
| 新生入学 | 只调用技能入口 | 展示 7 门课程及选修关系，背景与目标最多两个问题，不伪造学习证据 |
| 明确选课 | 电商运营，目标接企业项目，选择第③门第一节 | 进入指定课程，保存背景、课程与课节；`workspace_dir` 为项目绝对路径，产物绝对路径能读取；学生尚未完成的练习仍在进行中 |
| 暂停 | 今天先暂停，练习没做完 | 课程暂停，当前课节和未完成项保留，原产物不被清空或改判完成 |
| 新会话续学 | 在另一项目只调用入口 | 沿用背景，读取保存的原产物，接未完成动作，不重选题、不将旧文件误报丢失 |
| 旧存档定位 | 去掉目录锚点，仅保留相对产物路径后续学 | 找不到当前路径时请求原目录，保留证据，定位前不宣称文件丢失、不覆盖重建 |
| 旧存档恢复 | 提供真实原项目目录 | 实际读取并核对旧产物，补齐目录与绝对路径，清理已解决的路径缺口，保留背景、历史与其它未验证项 |

验证换目录续学时，记录原产物的 SHA-256。调用入口前后应能确认：它仍是同一个文件，学习状态未被提前升级。对一个未完成练习的恢复，不应凭导师自己的讲述判定学生已经掌握。

## 保存运行证据

Codex CLI 可用非交互会话保留 JSONL：

```bash
codex exec --ephemeral --sandbox workspace-write --json '$fde'
```

在已配置技能的隔离项目中执行；存档若放在项目之外，需按本机权限配置给予该测试目录写权限。沿用已有登录，不把密钥写进命令、仓库或日志。

检查 `command_execution` 等工具记录是否真的读过原课节、原产物和存档；退出成功或一句“已保存”不能单独证明流程正常。学员文件和完整会话属于本地测试证据，不纳入公开课程包。

## 结果边界

模型请求失败、额度用尽或账号不可用时，该场景记为未验证。远程更新检查不可用时，应继续本地课程。真实入学和续学通过，只证明当前版本、模型与场景中的流程，不替代教学效果、学习迁移或生产交付评估。
