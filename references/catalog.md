## 推荐规则

- 完全不知道从哪开始：推荐 ①；它对零基础也成立。
- 已经有企业客户或身边业务场景，想直接动手：推荐 ②，范围界定是所有交付的第一步。
- 已经在用 Claude Code / Codex，想把经验变成可复用资产：推荐 ③。
- 客户系统老旧、数据散落，不知道 Agent 怎么接进去：推荐 ④。
- Demo 做出来了但不敢给客户用：推荐 ⑤。
- 想看看别人的大作业做到什么程度算好：推荐 ⑦。
- 目标是求职、接单或创业：任意阶段插入 ⑧。

所有课程可直接选择。缺少基础时导师插入共享节点，不把推荐变成资格考试。

第②–⑤课可沿同一个本地模拟企业场景练习，先读 `references/lab-guide.md`；完整主题与产物关系见 `references/coverage.md`。每门课都可独立进入，导师补齐当前任务所需背景，不要求重复完成已经有证据的练习。
