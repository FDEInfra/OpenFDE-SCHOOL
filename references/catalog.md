# OpenFDE School · 课程目录

课程编号对应共学营课次，是稳定 ID，不是必修顺序。原共学营没有第 6 课，本校同样跳过 ⑥，第 ⑦ 门即原第 7 课（Demo Day），第 ⑧ 门为加餐课。`alpha` 已有独立 lesson 和实操；`beta` 已有可教大纲与最小实验，尚未完成全部 lesson 化。

## 我想先搞懂这个行业

| ID | 课程 | 一句话结果 | 状态 |
|---|---|---|---|
| ① | FDE 全景与企业需求挖掘 | 说清 FDE 是什么、谁需要它、企业为什么为结果付费，并能用热力图判断客户在哪 | alpha |
| ⑧ | 加餐：FDE 求职、作品集与创业路径 | 明确自己求职、接单或创业的下一段路径和作品集结构 | beta |

## 推荐规则

- 完全不知道从哪开始：推荐 ①；它对零基础也成立。
- 已经有企业客户或身边业务场景，想直接动手：推荐 ②，范围界定是所有交付的第一步。
- 已经在用 Claude Code / Codex，想把经验变成可复用资产：推荐 ③。
- 客户系统老旧、数据散落，不知道 Agent 怎么接进去：推荐 ④。
- Demo 做出来了但不敢给客户用：推荐 ⑤。
- 想看看别人的大作业做到什么程度算好：推荐 ⑦。
- 目标是求职、接单或创业：任意阶段插入 ⑧。

所有课程可直接选择。缺少基础时导师插入共享节点，不把推荐变成资格考试。
