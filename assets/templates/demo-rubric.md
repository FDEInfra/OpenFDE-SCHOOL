# FDE 项目评审量表

本量表用于学习复盘，不授予职业认证。每项按 0–2 记录：0 为缺证据，1 为部分成立，2 为证据可检查。模拟项目可展示完整方法，但不得按真实业务效果评分。

| 项目 | 2 分所需证据 | 记录内容 |
|---|---|---|
| 问题定义 | 使用者、流程与痛点有来源 | 来源或明确教学设定 |
| 范围与责任 | 做与不做、人工边界、验收人清楚 | SOW 与责任图 |
| 执行链路 | 主路径实际运行且能核对状态 | 命令、日志与运行版本 |
| 评估 | 正常、边界、失败有期望与结果 | 用例、报告、分母与局限 |
| 失败复盘 | 根因经过检验，有回归或待验证结论 | 失败记录、diff 或实验说明 |
| 移交与表达 | 受众能理解价值，并有运行说明 | 业务摘要与真实操作反馈 |

隐私泄露、冒称真实效果、越权写入或付款等问题不得由其他项目的高分抵消，应先停止相关发布或试点并处理问题。纸面计划、预期输出与真实执行分别记录。

评审结束形成三个结论：最可信的一项能力、目前最大的证据缺口、下一次最值得验证的动作。没有独立评审者时标明导师复核，不虚构评委意见。
